# AB Z Fruit - زحلقها
Android fruit puzzle game by AB Software. HTML5 game (`www/`) wrapped in an Android WebView (`app/`).
CI (`.github/workflows/build.yml`) builds `ABZFruit-debug.apk` (installable) and an unsigned release APK.

V1.1.1 / VC111: progressive fruit reserve, channel-only matching, lighter scenery. See PROGRESSIVE_V1.1.1.md.


Current safe patch: **V1.3.0 / VC123**. See `VC123_FRUIT_SIZE.md`.
