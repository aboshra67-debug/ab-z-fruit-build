# V1.2.1 / VC114 – Stability and visual refinement
Safe patch of VC113. Android package and save key unchanged.
- Replaced row-based reserve coordinates with deterministic radial dart scatter (minimum center spacing 2.32r); strict bottom-up release sequence and depth <=3 retained. Reserve is enabled for all playable stages; total fruit counts unchanged (24–500).
- Increased target radius by ~20%, adaptive to viewport and obstacle clearance; actual increase varies. Stage 8: radius 41 on 412x915, 33 on 360x640. Original safe obstacle clearance retained after lower placements caused jams. Added decorative non-colliding wooden supports behind crates.
- Overflow detection no longer depends on fifth fruit speed: four actual occupants plus overflow near mouth trigger loss after 1.65 s; a match or available slot resets the timer. Four occupied slots alone do not cause loss.
- Unfaded clipped sprite entry; full sprite required for release. Sky drawn without aspect distortion; original art reused and positioned to reveal hills. Soil, grassy edges and recessed earth-toned channel refined. Match particles and victory confetti increased.
- Verification: 300 stage initializations/counts/parity/hidden hit tests and 300 logical solution sequences on each of two viewport sizes. Real Matter.js solver finished levels 6,8,25,50,117,300 on both sizes (12 runs); solver defuses bombs and scares pests. Targeted overflow test passed on both; reserve motion and channel-only matching passed. Browser screenshot of level 8 produced via inline local assets, no page errors. No native Android device or measured FPS testing. No new original painted backgrounds or recorded audio.
- APK repacked from VC113, updated asset files and binary manifest version, v2 signed with existing shared test certificate (same as VC113), cryptographic signature/digest and zip CRC/alignment verified. Not a fresh Gradle build or release key. No new private signing material added to source.
