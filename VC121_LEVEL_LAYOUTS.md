# AB Z Fruit V1.2.8 / VC121
Baseline VC120. Package com.absoftware.zfruit. Save key/schema, fruit counts, types, progression, matching, four-slot channel, independent downward feed, and fixed-step physics integration unchanged. No previous file removed.

## Scope
- Five reusable terrain profiles: balanced, left-steeper, right-steeper, both-steeper, both-gentler. Actual collision surfaces and both render paths use the same per-side geometry. Channel stays centered and retains depth/capacity. Obstacle assignment alternates among left-first, right-first, outer-first, inner-first, and seeded shuffle, using existing safe placement bounds. Profiles repeat; this is not 300 separately hand-designed maps or a new moving-rock system.
- Levels 1–10 retain VC120 geometry after an initial trial of level 10 revealed a stalled solver path. Level 11 uses the left-steeper profile after a trial of its default geometry stalled on the short screen. Final targeted tests for these levels pass. No changes to fruit collision/force or feed rules to bypass these stalls.
- First bee visit delayed to 7–10 seconds (previously 1.8–3.8), repeat cooldown increased to at least 10 seconds, lock duration halved from 3 seconds to 1.5 seconds. The original insect/obstacle features remain. Bee/bird tips show once per app session for 1.2 seconds and do not interrupt an active tutorial. Existing sound/vibration settings unchanged.
- Terrain profile changes affect paths, density and stage duration; no universal speed or difficulty improvement is asserted. Current iteration preserves VC120's physics speed.

## Verification
- Both 412x915 and 360x640: generated counts, even pairs, order stack feasibility, terrain slope/collider geometry, obstacle clearance, hidden-input rejection, independent feed, no artificial jump/pass-through in controlled fixtures, queue handling, channel-only matching, overflow, crate motion and breakage, bee and bird behavior, ice, bomb damage and physics timestep. Full 300-level structural suites ran before early-stage corrections; final levels 1–11 revalidated separately. Tests use simulated paths, not all possible player choices.
- Browser rendered five profiles without JavaScript errors; tested non-repeating action hint and timeout. Preview is level 12. No physical Android testing, no production Play signing or GitHub modifications.
- APK updated from the original VC120 archive, not a fresh Gradle build. Native DEX/resources preserved. Existing v2 test-key signature/chunk digests checked, same certificate; assets match source bytes, ZIP CRC and uncompressed alignment checked.
- Controlled solver paths won on both sizes for levels 1, 5, 10, 11, 12, 13, 14, 15, 25, 80, 117, 300 (24 final representative level/size paths; unchanged early profiles reused). Initial failed/stopped trial logs are retained as evidence, not counted as passes. Final tall 117=458 s, 300=632 s; short 117=485 s, 300=629 s. Level 300 is somewhat slower than VC120 in this solver; simulation rate itself is unchanged.
