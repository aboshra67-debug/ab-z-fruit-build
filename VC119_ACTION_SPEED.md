# V1.2.6 / VC119 — Distribution, speed and action
Baseline: VC118. Same save schema, package, original test signing certificate, 300-level count curve, base four-slot channel, matching restrictions and independent reserve motion. No previous source file deleted. No GitHub writes.

- Initial seeded scatter uses a wider randomized generation window and bounded micro-offsets with solid clearance checks, plus fixed per-fruit visual rotation maintained at release. The new layouts vary in density and pair spacing; this is not a claim that every board is harder. Logical stack depth remains at most three unmatched fruits.
- Physics advances at 125% of the old simulation rate, using the same 1/240-second integration step. The reserve still uses the VC118 independent downward swept-clearance movement and the same rate limits. No upward impulse, forced fruit repositioning or collision bypass added. Pair disappearance effect shortened; channel matching conditions unchanged.
- Crates move and rotate within a bounded envelope, pause before fruit contact, and preserve a full fruit-width lane between obstacle and side wall. A blocked passage was found in intermediate level 80 testing and corrected by limiting crate positions. Crates still break after distinct impacts. Rock and crate debris, bomb rings and combo particles are visual only, with bounded particle counts; no launch force. Bees start at level 9 and birds at level 12, with faster approach and shorter bee occupation. Existing bombs, ice, cages, currency and progression retained.
- Final Node tests on 412x915 and 360x640: 300 level counts and logical orders on each size, reserve motion, blocked support, queued taps, match-channel boundary, moving fifth fruit, crate impacts, ice, bird rescue and bomb accounting all passed. New fixed-step speed, crate wall gap and occupied-sweep checks passed on both sizes. Controlled solver won levels 1, 5, 10, 25, 80, 117 and 300 on both sizes (14 paths). Tall simulated completion times: level 10 90s, 80 362s, 117 518s, 300 646s. Short: level 10 95s, 80 385s, 117 515s, 300 683s. These are simulated game times, not human play times; not all possible player paths were tested. Browser preview reported no JS errors.
- APK is repackaged from VC118 with updated web assets and version metadata, not a fresh Gradle build. V2 RSA signature and chunk digests verified, same certificate, all packaged web assets match source, ZIP CRC/alignment checked, native DEX/resources unchanged. Physical Android device performance and human difficulty parity remain unverified. Faster simulation increases physics work; device frame rate must be measured separately.
